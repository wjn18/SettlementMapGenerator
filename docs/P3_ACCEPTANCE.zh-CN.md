> 历史验收记录：旧版源码与专用工具已在迁移完成后移除。本文的 `verify:upstream`、`legacy:*`、`baseline:*` 命令仅适用于清理前提交；当前命令及历史复现入口见 [上游来源](UPSTREAM.md)。

日期：2026-09-29。P3 正式地图预览已实现。生成内核、数据格式和算法版本保持 P2 状态；下一阶段为 P4 稳定性与库交付。

## 交付

- `packages/map-scene`：无 DOM 绘制指令，旧版六种配色、明确的世界/屏幕笔画单位、端帽/连接、图层顺序与地块命中区域。
- `packages/renderer-openfl`：OpenFL 9.5.2 / WebGL2 绘制，CSS 视口、DPR 调整、几何命中和幂等销毁。不会重新生成地图，API 不暴露 Sprite。
- `apps/playground`：真实城镇、种子和规模调整、广场/城堡/城墙自动或显式开关、随机种子、六种主题、滚轮缩放、拖动平移、键盘操作、复位、街区悬停提示、JSON 文件导入导出、URL 参数与错误恢复。
- 继续使用上游 maroubra 位图字体显示英文图名；中文操作和提示使用系统字体，文字布局独立于地图几何。窄屏控件转为上下布局，未手动移动的视口在尺寸改变时重新适应城镇。
- 六张固定数据截图、旧图对照统计、自动化测试和模块使用文档。

入口：`npm ci` 后运行 `npm run dev`，打开 [地图工坊](http://127.0.0.1:5174)。`npm run build` 编译三个包和两个应用；`npm run preview` 在 4174 预览生产产物。原 P1 固定几何实验保留，使用 `npm run dev:probe` / `npm run preview:probe`，端口 5173/4173。

## 绘制兼容

移植参照 `mapping/CityMap.hx`、`Brush.hx`、`Palette.hx` 和 `PatchView.hx`。外部道路先画宽 2.3 的外线，再画宽 1.7 的纸色内线；城区街巷保留原先的建筑留白表示。普通建筑按地块顺序填色和描边，公园使用 medium 色。城堡/教堂先画全部轮廓，再画全部填充，避免把建筑分块共享边暴露出来。城墙、城门横杠和塔楼在顶部，城堡塔楼半径放大 1.5 倍。命中区域独立于可见建筑，空白地块仍可提示用途。

固定截图直接消费 P1 保存的 Haxe 几何，经测试专用 DTO 转换后交给新绘制器；没有调用新生成器来替代参考输入。缩放使用旧版 cityRadius，中心固定为 (0,0)。默认页面的“适应城镇”则按当前城区包围框留边展示。

与 P1 的独立截图比较仅排除旧版右上四个按钮区域，其他地图像素均计入：

| 种子 / 规模 | DPR | 平均 RGB 通道绝对误差（0..255） | 任一通道差 >16 的像素比例 |
| --- | --- | --- | --- |
| 42 / 15 | 1 | 0.5760 | 1.6206% |
| 1 / 6 | 1 | 0.1353 | 0.3862% |
| 12345 / 24 | 1 | 0.6709 | 2.0018% |
| 12345 / 24 | 2 | 0.4602 | 0.9473% |

阈值固定为平均误差 <1、差异像素比例 <2.5%，不宣称旧 OpenFL 8.9 与 npm 9.5 的抗锯齿逐像素一致。已人工查看桌面、窄屏及城墙/城堡截图。另保存三个种子各 DPR=1/2 的新绘制截图，开发与生产使用同一组基线；JSON 重载要求像素输出的 PNG 字节完全一致。详见 [截图说明及哈希](../tests/fixtures/p3/README.md) 和 [统计](../tests/fixtures/p3/report.json)。

## 验证

环境：Windows x64、Node.js 24.19.0、Chrome 153.0.8010.53、OpenFL 9.5.2、Vite 8.3.1。

| 验证 | 结果 |
| --- | --- |
| `npm run test:p3` | 6 项 Node 测试：独立场景、绘制层级、主题、命中、视口、截图哈希 |
| `npm run test:p3:browser` | 16 项浏览器测试；开发/生产 × DPR=1/2，全通过 |
| P2 Node 回归 | 原 43 项测试全部通过；core 源码未修改 |
| 参考源码及 P1 基线校验 | 64 个上游文件、P1 数据与图片保持不变 |
| 完整构建 | core、map-scene、renderer-openfl、playground 和原 probe 通过 |

浏览器测试覆盖参数/URL、主题切换不触发生成、悬停、缩放平移、JSON 下载/导入、损坏 JSON 保留现有地图、非法 URL 恢复、固定数据截图、动态 DPR、尺寸变化与窄屏无横向溢出。重复销毁/挂载三次后只有一个画布，浏览器全局监听器和待调度 RAF 没有累积。已排队的旧回调最多执行一次空函数，不会继续调度。

OpenFL 的声明中 `Stage.application` 在此版本没有对应运行字段，实际通过 `Stage.window.application` 访问。HTML5 后端缓存 DPR，且公开 `exit()` 未清理 RAF。版本兼容处理集中在适配器 `runtime.ts` 和 `resize` 中；升级依赖应重新验证这些接入点。

## 使用与范围

```sh
npm ci
npm run build
npm run test:p3
npm run test:p3:browser
npm run dev
```

URL 支持 seed、size、plaza、castle、walls、maxAttempts、theme。导出保存完整 TownData；导入经过 P2 校验，保留实际几何及原始版本，不按种子重新生成。URL 只记录参数，不携带导入文件的完整几何，跨引擎精确保留地图应继续使用 JSON。

地图图形通过 OpenFL WebGL2 输出；未验证其他浏览器或原生目标。生成目前在主线程同步执行，极端失败重试可能短暂阻塞界面；Worker、广泛种子压力测试和独立打包消费属于 P4。绘图库自身的 eval 与大包构建提示仍存在，核心包不受其依赖影响。P3 未修改算法、发布 npm 包或部署网站。
